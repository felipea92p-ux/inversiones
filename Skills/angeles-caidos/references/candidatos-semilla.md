## Cómo usar esta tabla

1. Elegir una fila.
2. Confirmar o sustituir el "ganador candidato" — tiene que ser una empresa real, del mismo sector
   o uno directamente comparable, que en la fecha de corte se viera igual de fuerte.
3. Fijar la fecha de corte exacta (año fiscal, no solo el año natural) para ambos casos del par.
4. Seguir el protocolo de `SKILL.md` desde el paso 3.

## Ampliar la lista

Cuando se investigue un par de esta tabla, es habitual que aparezcan 1-2 pares nuevos por
asociación (un competidor mencionado, un caso citado en un informe). Añadirlos aquí con la misma
estructura, para que la lista crezca con el uso en vez de tener que rehacerse cada vez.
